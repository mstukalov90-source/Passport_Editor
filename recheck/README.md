# Recheck — проверка геоподосновы

Приложение автоматически создаёт одно событие «Проверка геоподосновы» после того,
как исходный `approval.Approve` получает `approved=True`.

Участники события:

- пользователь организации задания: `OwnerLegalPersonId` берётся только из
  основного события, связанного с `taskguid` (владельцы `n_root`/`v_root` доступа не получают);
- любой пользователь с ролью `MGGT` как инспектор.

Оба участника должны независимо нажать «Согласовать». Событие закрывается после
двух согласований либо по истечении пяти следующих рабочих дней (понедельник–пятница).
Для гарантированного закрытия без посещения страницы следует запускать по расписанию:

```bash
python manage.py expire_rechecks
```

## QGIS API

`GET /recheck/api/qgis/changes/?status=pending&task_guid=<uuid>` возвращает плоский
массив `rows`: одна строка соответствует одному изменяемому атрибуту объекта.
В каждой строке есть слой, ключ и `root_id` объекта, старое и новое значение,
геометрия GeoJSON и идентификатор запроса.

Тот же плоский набор доступен QGIS напрямую как представление БД
`recheck.qgis_changes`; геометрия хранится в SRID 4326.

После внесения изменений оператор отмечает запрос выполненным:

`POST /recheck/api/qgis/requests/<request_id>/complete/?user=<login>`.

Доступ QGIS API ограничивается общей настройкой `APPROVAL_QGIS_ALLOWED_HOSTS`.
